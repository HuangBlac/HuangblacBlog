01 / 作品

什么作品可以来

主题不限。数学、计算机、人工智能、少女乐队相关内容都欢迎；其他主题也可以。文字、代码、网页、PPT、旧作或团队作品均可提交。一个人可以投多件不同作品，同一作品的不同版本只算一件。

没有字数或人工写作比例门槛。每件作品须有可供评审的实际内容，并告诉我怎样阅读、运行或体验；只有想法、没有作品内容的计划不算有效投稿。

这里允许并鼓励使用 AI。请说明 AI 做了什么，你做了什么。写作作品尤其欢迎说明选题、筛选、修改和定稿过程；AI 写出全部初稿也可以参赛，不要求达到某种人工改写比例。

旧作可以参赛。团队作品请列出作者、分工、引用或素材来源，并指定一位联系人。参赛者须确认自己有权将作品及所用素材公开展示。

02 / 投稿

作品怎么交

邮件

把命名含“高松灯杯”的作品压缩包发送到以下任一邮箱。若附件太大，可以在邮件里提供可访问的下载链接，并让链接至少保持到结果公布后可用。

  • huangblac@gmail.com
  • 1239256942@qq.com

邮件请写明作品名称、公开署名、私下可用的联系方式、阅读或体验方法，以及 AI 的参与方式。团队另写成员、分工和联系人。公开署名可以用真实姓名、笔名或网名；只要能联系到你即可。

以两个邮箱中最早的系统收件时间为准。主办人收到后会发回执；若没有收到回执，请在截止前向另一个邮箱重投或到仓库 Issue 咨询。发件截图不能代替实际收件记录。

GitHub PR

代码类作品也可以向 TomoriCup 活动仓库 ↗提交 Pull Request。PR 创建时须已有实际作品内容和使用说明；空 PR 不占位。PR 被合并表示收录，不表示获奖。

截止前可以更新作品；邮件以最后收到的有效版本、PR 以截止前最后一次有效提交为评审版本。若同一作品同时通过邮件和 PR 提交，请注明对应关系，避免重复计件。截止后不接受新的作品版本。

Issue 用于咨询、异议和必要时的同分投票，不作为作品投稿渠道。你可以在仓库 Issues ↗提出问题。

有效投稿

作品须在通告公开后、截止前到达，且届时确有可评审内容、可用的阅读或体验方式、可联系的作者。截止时文件损坏、链接失效、访问权限未开放，或只有空计划的作品，不列入有效名单，也不接收截止后的作品补交。

请在投稿时说明公开权限、AI 使用，以及团队与素材来源等适用信息。若仅缺少这些说明，主办人可请作者补齐文字资料；补充说明不能替换作品内容，评分名单冻结前仍未补齐的作品不列入有效名单。

03 / 评选

怎么评分，何时公布

由我主评。完成度占 50 分，可体验与可检验程度占 30 分，想法占 20 分。每件有效作品都会公开三项分数、总分和一段简评；获胜作品另写获奖理由。读者反馈可以参考，平时的点赞不直接决定奖项。

目标是在 11 月 22 日公布有效名单和评分，11 月 23 日公布结果。如果投稿量或核查工作使评审赶不上这一安排，我会在 22 日先公布进度、原因和新的评分、投票与结果时间，不仓促打分。

若出现并列最高分，将在 仓库 Issue ↗ 公布并列作品编号并投票。所有 GitHub 账号都可参加，每个账号按截止前最后一条有效评论中的作品编号计一票；如按原计划启动，投票于 11 月 23 日 20:00（北京时间）截止。截止后编辑的评论不计，删除的评论视为弃票。主办人保存计票记录；同票或无人投票时由我裁定，并公开理由。若评分延期，投票时间也会一起更新。

04 / 奖项

奖名有点绕，规则很简单

截止前提交至少一件有效作品的作者，每人获得一次参与奖，名字叫“第三十六届全国高松灯杯黑客松竞赛冠军”。一人投多件也只记一次。团队作品的参与奖名单由团队内部讨论，联系人把结果告知主办人。

总分最高的作品获得“路过参与奖”，以及固定人民币 68.6 元的小灯玩偶购买金。获奖者自行选购，不需要购买凭证。团队指定联系人统一领取购买金。这些奖名是自办活动的趣味命名。

我的个人作品可以放在仓库展示，但不参加正式评分、排名或获奖。若截止时没有有效的外部投稿，我会如实公布无获胜作品，再选一件自己的作品作结赛展示，自己买一个小灯玩偶留念。

结果公布后我会私下联系获胜者。若 14 天内仍未确认收款方式，获奖记录保留、购买金暂不转账，也不会自动改发给下一名；之后仍可联系我领取原奖项。

05 / 公开与撤回

投稿前请看这一段

投稿即授权本活动在公开的 TomoriCup 仓库收录和展示作品及你选定的署名。PR 本身会公开。邮件原件和原始压缩包只供主办人核对，不直接上传；仓库展示经检查的作品文件与使用说明。请先确认作品和所用素材有权公开，不要附密码、私人资料或未经许可的材料。

公开收录不授予其他读者复用、改编或再分发作品的额外许可。GitHub 平台允许浏览和 fork 公开仓库；这不等于可以把作品拿去另作他用。联系邮箱和发奖所需的收款信息不会公开。

作者可以随时申请撤回。结果公布前撤回的作品退出评选；结果公布后，我会移除自己能控制的作品展示与当前评分，已公布的获奖事实标记为“撤回”，不重新排名，也不追回已发奖金，未发购买金则不再支付。已经产生的 GitHub 提交历史或他人的 fork 可能仍能看到，无法保证彻底清除。

邮件原件和压缩包仅用于收件核对、评审和争议处理，原则上在结果与争议处理结束后 90 天内删除；未解决争议仅保留必要材料至结案。私下提供的收款资料在发奖确认后 30 天内删除。

规则疑问、投稿接收问题或评审异议，可以在 TomoriCup Issues ↗ 提出；涉及联系方式和收款资料时，请使用上方邮箱私下联系，不要把它们写进公开 Issue。
